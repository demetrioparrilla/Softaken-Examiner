# Softaken-Examiner
Softaken Examiner is a powerful Windows-based email forensic examination software built for investigating, analysing, and managing digital email evidence. It supports other file types, including PST, OST, EML, MSG, MBOX, etc. Users can search emails, check message headers, attachments, metadata and communication patterns, validate file integrity using SHA-256 hashing and generate extensive reports. It facilitates digital investigations, compliance reviews, and incident response with advanced case management, timeline analysis, OCR capabilities, and flexible export options.
